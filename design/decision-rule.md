# Decision rule

Fix this before measuring. A change counts as a saving only if all hold:
1. Median billed $ per session (or ACU per session) is **≥ 10% below** the baseline.
2. In controlled A/B: **every rep** is below the baseline’s worst rep (n ≥ 3 per cell).
   In real-work pilots: **≥ 20 sessions per side** with a similar task mix.
3. Quality is **not lower**: task success, hidden graders or review findings.

Becomes a team default when it passes in ≥ 2 teams. Re-evaluate tools every quarter.
Why: single runs swing ±30% on short tasks; in our v2 run, four tools looked 11–28% cheaper after rep 1 and none were after rep 3.
