# Deck style

- Single HTML file + `assets/deck.css`, `assets/deck.js`; 1600×900 canvas; ← → keys, `#n` links, `N` notes.
- Ink-on-paper palette with one blue accent; red only for "costs more". Light and dark from the same tokens.
- Charts as inline SVG: one axis, labeled values, blue/red pair validated for color-blind safety.
- Slide text in English; speaker notes may be in the presenter’s language.
- Every number carries its source in the slide footer.
