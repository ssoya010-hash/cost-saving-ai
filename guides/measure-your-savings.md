# Measure your savings

1. Install [cost-coach](../utils/cost-coach/) and run `cost-coach status` to see your baseline.
2. Mark the change: `cost-coach mark "<what you changed>"`.
3. Work normally for 1–2 weeks with a similar task mix (≥ 20 sessions).
4. Compare: `cost-coach compare` (median billed $ per session; Devin: ACU per session via `cost-coach devin add`).
5. Apply the [decision rule](../design/decision-rule.md); report in the tool’s `playground/<tool>/RESULTS.md`.

Pitfalls: one run lies (±30% noise on short tasks), token counts are not dollars, and a different task
mix changes the bill more than most tools.
