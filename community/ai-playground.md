# #ai-playground (proposal)

**Goal:** close the gap in AI usage across teams with one shared loop: **try → measure → share → adopt**.

| Step | What | Where |
|---|---|---|
| Try | Pick a tool or habit | [playground/](../playground/), [guides/](../guides/) |
| Measure | Billed $ per task with cost-coach | [guides/measure-your-savings.md](../guides/measure-your-savings.md) |
| Share | Post a short result; add a RESULTS.md row or an experiment folder | channel + PR |
| Adopt | Passes the [decision rule](../design/decision-rule.md) in ≥ 2 teams → GOT default | guides/, skills/ |

Asks: GOT sponsorship for the channel; 3–5 volunteer teams for the first pilot.
