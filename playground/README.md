# Playground

One folder per tool. Each has the same structure so results are comparable.

The full table is generated in the [root README](../README.md#playground-tool-cards) from each card’s front matter.

Add a tool: `cp -r _template <tool>` and fill in the README.
Loop steps: ① prompt · ② agent turn · ③ tool calls · ④ model + cache · ⑤ output (see [guides/tool-verdicts.md](../guides/tool-verdicts.md)).
